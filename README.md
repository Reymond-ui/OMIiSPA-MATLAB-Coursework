# ОМиИСПА — курс MATLAB: лекции и лабораторные работы

Материалы курса «Основы моделирования и исследования систем программного автоматического управления»: конспекты лекций и восемь выполненных лабораторных работ, от базового построения графиков до моделирования двигателя и гребного движителя.

Репозиторий задуман как рабочая тетрадь курса: по каждой теме лежит отдельная папка со скриптами и моделями, которые можно открыть и прогнать в MATLAB 2025.

## Что внутри

| Папка | Тема работы |
|-------|-------------|
| `LW1` | График функции и первые шаги в ТАУ: построение и оформление зависимостей |
| `LW2` | Автоматическое построение графиков по данным из внешних файлов |
| `LW3` | Подбор решателя: как выбор solver'а влияет на результат и время расчёта |
| `LW4` | Решение дифференциального уравнения, описывающего систему |
| `LW5` | Моделирование двигателя: механическая характеристика и кривая управления |
| `LW6` | Расчёт и моделирование гребного движителя |
| `LW7` | Лабораторная работа №7 |
| `LW8` | Лабораторная работа №8 |
| `Lections` | Лекционные материалы курса |

## Как пользоваться

Каждая лабораторная — самостоятельная папка: открываете её в MATLAB 2025, запускаете `.m`-скрипт или `.slx`-модель. Порядок работ совпадает с порядком тем в курсе, поэтому удобнее идти по папкам сверху вниз.
